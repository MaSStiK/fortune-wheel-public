# Колесо Фортуны

</div>

**Колесо Фортуны** - интерактивное онлайн-колесо для случайного распределения подарков среди пользователей. Проект занял второе место на конкурсе «Выставка Petомцев» от ProductStar.

## ✨ Возможности

- Колесо с 8 секциями, каждая из которых соответствует определённому подарку
- Индивидуальная вероятность выпадения для каждой секции
- Одно участие на пользователя; повторное участие запрещено

## 🎯 Цель проекта

Создать работающее колесо фортуны для повышения вовлечённости участников ProductCamp и привлечения потенциальных покупателей курсов ProductStar.

## 📝 Задачи проекта

1. Реализовать проект в соответствии с техническим заданием
2. Описать потенциальных пользователей продукта
3. Составить план разработки и дорожную карту проекта, определить формат взаимодействия и коммуникации в команде
4. Разработать дизайн колеса, экранов сайта, форм регистрации и консультации в соответствии с брендбуком
5. Создать понятный интерфейс взаимодействия с колесом: первый экран, призы, форма регистрации, полученный приз, форма связи с консультантом и само колесо
6. Создать сайт и обеспечить адаптивность и кросс-браузерную совместимость
7. Реализовать механику вращения колеса с учётом заданных вероятностей
8. Обеспечить безопасность передачи данных и хранения статистики использования
9. Создать базу данных с информацией об участниках, призах и вероятностях их получения. Предусмотреть возможность изменять количество призов и ограничить участие каждого пользователя одним разом
10. Обеспечить работу сайта при нагрузке в 100 пользователей

## ⚙️ Механика использования

1. Пользователь регистрируется на сайте для участия
2. После регистрации пользователь нажимает кнопку «Крутить», чтобы запустить колесо
3. Колесо останавливается на одной из 8 секций, определяя подарок и промокод пользователя
4. Зарегистрированный пользователь получает промокод и ссылку для его активации по электронной почте
