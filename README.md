# Wheel of Fortune

</div>

**Wheel of Fortune** is an interactive online wheel designed to randomly distribute gifts to users. The project took second place in ProductStar’s “Pet Project Exhibition” competition.

## ✨ Features

- A wheel with 8 sections, each representing a specific gift
- An individual winning probability for each section
- One participation per user; repeat participation is prohibited

## 🎯 Project Goal

Build a working prize wheel to increase engagement among ProductCamp participants and help ProductStar attract prospective course buyers.

## 📝 Project Tasks

1. Implement the project according to the technical specification
2. Describe the product’s potential users
3. Create a project development plan and roadmap, and define how the team will collaborate and communicate
4. Design the wheel, website screens, and registration and consultation forms according to the brand guidelines
5. Develop a clear interface for interacting with the wheel: the initial screen, prizes, registration form, awarded prize, consultant contact form, and the wheel itself
6. Build the website and ensure responsive design and cross-browser compatibility
7. Implement the wheel-spinning mechanism using the specified probabilities
8. Ensure secure data transmission and storage of usage statistics
9. Create a database containing participant data, prizes, and their winning probabilities. Provide the option to change the number of prizes and limit each user to one participation
10. Ensure the website can handle a load of 100 users

## 👥 Target Audience

Participants attending ProductCamp online or in person:

- Product managers
- Project managers
- CPO
- Analysts
- Product designers

## ⚙️ How It Works

1. The user registers on the website to participate
2. After registering, the user clicks the “Spin” button to start the wheel
3. The wheel stops on one of its 8 sections, determining the user’s gift and promo code
4. The registered user receives the promo code and its activation link by email
